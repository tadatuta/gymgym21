# Миграция данных

Runtime уже использует только PostgreSQL: JSON-хранилища и snapshot endpoints удалены. Auth и доменные таблицы используют один pool; SQL-миграции применяются при старте под session advisory lock, каждый файл — одной транзакцией.

Для переноса старых JSON используйте [Legacy Import в runbook](docs/runbook.md#legacy-import): сначала файловый dry-run, затем проверенный manifest и apply в сервисное окно. Dry-run не проверяет текущее содержимое БД; apply проверяет ownership и весь план до атомарной записи. Не удаляйте исходники и единственные копии данных.

Восстановление личного JSON backup через интерфейс — отдельная операция: [резервная копия аккаунта](docs/runbook.md#резервная-копия-аккаунта).
